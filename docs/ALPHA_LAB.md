# Alpha Lab

Use the [user guide](USER_GUIDE.md#screen-in-alpha-lab) for fast screening,
settings and saved results. This filename is retained for workbench references.
Run `python -m qlib_yahoo alpha operators` with the installed Python for the
current operator list. Lab uses bare FASTEXPR field names and fixed-book
simulation; Qlib detailed validation uses a separate expression/accounting path.
See [SEC fields](SEC_FIELDS_USER_GUIDE.md) and [limitations](LIMITATIONS.md).
