# Verified runtime

Use [INSTALL.md](INSTALL.md) to install or recover the accepted runtime.
The machine-readable pins are `qlib-derivative-pin.json` and
`qlib-fast-runtime.v1.json` beside this page. Do not change their hashes to
accept an altered installation.

CPython 3.12 is required. Windows x64 consumes the bundled verified native zip;
GitHub CLI/private access is unnecessary. macOS uses a separate engine/profile
without the Windows helper. Runtime verification is not a legal/platform
clearance or a performance guarantee. See [architecture](ARCHITECTURE.md) and
[limitations](LIMITATIONS.md).
