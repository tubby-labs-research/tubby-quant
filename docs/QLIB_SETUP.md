# Qlib setup

Use [INSTALL.md](INSTALL.md) for current setup, launch and recovery commands.
This filename remains available because runtime errors reference it.

The accepted signed profiles require CPython 3.12. Windows x64 uses a bundled,
hash-verified native archive with no GitHub CLI or authentication requirement.
macOS selects its own pinned engine and remains experimental pending real-Mac
acceptance. Keep the complete source distribution and use an
external data root; public package/source downloads still require connectivity.
See [architecture](ARCHITECTURE.md) and [limitations](LIMITATIONS.md).
